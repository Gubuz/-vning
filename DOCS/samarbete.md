# Samarbete i ett repository

Ett gemensamt repository används för att flera utvecklare ska kunna arbeta med samma projekt.

Med Git kan utvecklarna spara sina ändringar i commits och dela dem med resten av teamet. Det gör det enklare att se vem som har gjort olika förändringar och att följa projektets versionshistorik.

Utvecklare kan även arbeta i olika branches för att utveckla funktioner utan att direkt påverka huvudversionen. Ett gemensamt repository gör därför samarbetet mer strukturerat och minskar risken att olika versioner av projektet blandas ihop.
